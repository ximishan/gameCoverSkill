# Game Taxonomy Reference

Use this reference before choosing a cover template. The key rule is to separate **genre** from **presentation/marketing tags**.

## 1. Genre = what kind of game it is

Examples:

- `grand-strategy` — 大战略 / 宏大战略
- `strategy` — RTS / SLG / 塔防 / 常规策略
- `roguelike` — 肉鸽 / Roguelike
- `shooter` — FPS / TPS / 枪战
- `rpg` — RPG / ARPG / JRPG
- `simulation` — 模拟 / 经营 / 建造

Genre decides the visual system.

## 2. Presentation tag = how the cover introduces it

Examples:

- `大型单机`
- `PC单机`
- `Steam移植`
- `中文汉化`
- `安卓直装`
- `完整版`
- `大战略`
- `历史策略`

Presentation tags should help a broad audience understand the game quickly. They do not replace the underlying genre.

## 3. Feature claim = specific supplied selling point

Examples:

- `解锁全部DLC`
- `完全汉化`
- `内置存档`
- `版本号 11.0.78`
- `PC+安卓`

Feature claims must come from the user or another reliable supplied source. Never invent them.

## Grand Strategy vs ordinary Strategy

Use `grand-strategy` when the player primarily controls a country, realm, civilization-scale polity, or empire through several interlocking systems such as diplomacy, economy, politics, religion, trade, technology, colonization, warfare, or long-term national development.

Typical titles:

| Game | Genre route | Useful cover tags |
| --- | --- | --- |
| 欧陆风云4 | `grand-strategy` | 大型单机 / 大战略 / 历史策略 |
| 钢铁雄心4 | `grand-strategy` | 大型单机 / 二战战略 / 大战略 |
| 十字军之王3 | `grand-strategy` | 大型单机 / 王朝经营 / 大战略 |
| 维多利亚3 | `grand-strategy` | 大型单机 / 国家经营 / 大战略 |
| 群星 | `grand-strategy` | 大型单机 / 星际战略 / 大战略 |

Use ordinary `strategy` for games whose main identity is tactical battles, RTS base/unit control, tower defense, or conventional SLG systems without the broad country/empire simulation emphasis.

## About “大型单机”

`大型单机` is a broad audience-facing descriptor, not a technical genre. It can be useful when a title is a substantial PC game with a meaningful single-player experience, but it must not imply:

- the game has no multiplayer
- the game works fully offline
- the game is AAA
- the game is large only because of file size

When precision matters, pair it internally with the real genre:

```text
欧陆风云4
Genre: grand-strategy
Presentation tag: 大型单机
Platform: PC
```

This allows the cover to say something immediately understandable while the renderer still chooses the correct grand-strategy visual template.
